Limitations / unfinished verification

  creation. Desktop/mobile visual preview and interactive downloads could not be
  tested in Chromium, Safari/iOS, Firefox, Edge or real Android devices.
- PNG PDF aspect ratio was tested. Real-browser PNG/JPEG/WebP decode/resizing,
  corrupt/oversized image handling, canvas orientation and device storage quota
  need browser checks. DOM tests do not substitute for browser layout/decoding.
- CDN/font loading failures, offline reload and browser download behavior need
  real-browser checks. Editor has a PDF-dependency failure message; CDN scripts
  are still required to generate PDFs.
- Existing PDF built-in fonts are retained. Non-Latin scripts/emoji and unusual
  glyphs are not validated; a suitable embedded font may be needed for those.
- No live server/cPanel configuration, hosting cache or production deployment tested.
